# 👻 Whisper Hollow

### A 2-Player Co-op Horror Extraction Game | Built for YouTube Playables & Offline Play

---

## 🎮 The Game

**Whisper Hollow** is a tense, two-player co-op game where communication is your only weapon. You and a friend control two lost souls trapped in an abandoned village. To escape, you must:

1. **Search** for 3 hidden relics — but relics only unlock when BOTH players stand near them
2. **Survive** — each relic angers a wandering spirit that hunts the closest player
3. **Extract** — once all relics are found, a gate appears. Both players must reach it within seconds to win

If one player is caught… **both lose.**
